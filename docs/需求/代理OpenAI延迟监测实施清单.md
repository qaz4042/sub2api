状态：闭环 A、B 已实现，已完成本地探测桩、PostgreSQL、前端定向及独立弹窗浏览器验证。未部署、发布或推送；未完成项保留空框，详见末尾实施记录。

## 一、范围与统一口径

为选定代理开启后台监测，支持每 10／30／60 秒采样，记录成功与失败；代理页查看最近状态和历史趋势，关闭页面后继续采样。默认全部关闭，开启时默认间隔 30 秒，首版仅按代理配置。

首版不含批量配置、多代理对比、告警、自动切换、账号恢复、模型推理测速、自定义目标或通用任务平台。结果不参与现有代理健康判定、账号统计、用量或计费；手动测速保持原有行为，不计入定时样本。

| 项目 | 统一约定 |
| --- | --- |
| 探测目标 | 复用 `https://api.openai.com/v1/models`，不发送账号密钥、不调用生成接口 |
| 成败 | HTTP 200／401 为连通成功；403、429、5xx、连接失败、超时分别记录并计为失败 |
| 延迟 | 复用现有 prober，计时从发起请求到响应头返回，不含随后读取响应体的耗时；客户端复用连接，仅新连接包含建连、TLS 等耗时，不代表 TTFT 或模型速度 |
| 汇总 | 成功率 = 成功数 / 已完成样本数；平均延迟、P95 仅用成功样本，失败不填 0ms；无样本或全失败时延迟为空 |
| 缺测 | 未采样、暂停、调度跳过、服务停机不计成败；展示样本数、最近采样时间和过期状态，趋势缺失桶留空 |
| 时间 | UTC 存储、用户时区展示，查询区间左闭右开 |
| 配置隔离 | 协议、地址、端口、凭证的连接指纹与监测调度版本分开；当前状态、历史汇总、趋势及最近记录均只查询当前连接指纹，连接变化且无匹配样本时显示“当前配置暂无样本”；旧指纹样本按保留期清理，首版不提供旧配置查询；单纯调整采样间隔不切断同一连接的历史，历史不保存连接密码 |
| 保留期 | 原始样本保留 7 天，定时分批清理；先按原始样本查询聚合 |

### 执行与恢复

- [x] 复用现有 prober，保持约 10 秒超时及手动测速语义；探测失败与保存失败分别记录，数据库错误不计为线路失败。
- [x] 独立 Runner 按秒扫描到期配置，不依赖分钟级账号 cron；采用有限 worker、有限待处理量并错开初始执行时间，校验代理可监测及并发额度，跳过时记录运行状态。
- [x] 首版容量基线为同时启用 10 个代理、均采用 10 秒间隔，默认每实例 16 个 worker；并发上限按实例生效，同一代理跨实例由数据库租约互斥，不另建全局限流系统。超出基线仍采用有界执行及跳轮策略，不承诺原采样频率；记录实际 worker 数与调度偏差验收结果。
- [x] 数据库原子领取并设置有期限的租约，覆盖探测与保存上限；正常情况下同一代理仅一个任务，允许极端卡顿、租约到期时出现重复探测，以拒绝失效 worker 落库保证结果一致性，不增加复杂分布式锁。
- [x] 领取时捕获连接指纹；保存结果及推进调度时，原子校验租约有效期、所有者、执行标识、调度版本及当前代理连接指纹和可监测状态。读取当前状态也须匹配连接指纹，暂停或配置变化后旧任务不得更新当前结果或调度。
- [x] 按计划时刻推进，积压或执行超周期时跳过过期轮次，不补跑、不无限排队、不主动重叠探测或自动重试；间隔为目标周期，10 秒档遇到接近超时的请求可能跳轮，属于缺测。允许调度偏差，不以“执行完成再等一个周期”充当固定周期采样。
- [x] 领取与完成各使用短事务，探测期间不持有数据库事务；保存失败的轮次视为缺测，不重新探测。租约恢复时废弃旧执行标识，将调度推进至下一未来计划时刻，再按正常流程领取新轮次；数据库暂不可用时等待恢复，不因旧任务未推进而反复领取旧轮次。
- [x] 暂停、停用、过期、删除后停止新任务；未启用时不产生探测流量，运行异常仅影响监测，不阻断业务请求。
- [x] 退出时停止领取，取消或有界等待运行任务；崩溃后租约到期可恢复，不补跑停机数据。

### API 与运行约定

- `GET /api/v1/admin/proxies/:id/openai-monitor?hours=1|24|168&page=1`：配置、可监测状态、最新样本／过期标志、汇总、趋势、50 条分页明细、实际覆盖区间及 `truncated`。最大页码 2000，最大 168 桶；请求上下文超时 10 秒。汇总与明细在同一个只读 repeatable-read 快照查询，按当前连接指纹过滤。
- `PUT` 同路径：`{"enabled":false,"interval_seconds":30}`。仅支持 10／30／60 秒；开启须存在且未删除、未停用、未过期。返回 `saved` 后重新读取状态；关闭配置不会删除历史。
- 默认未配置、关闭、30 秒。每秒扫描，16 worker、无等待队列；首次按代理 ID 对周期取模错开。逾期超过 2 秒的轮次跳过，避免停机后追赶。
- 每次领取以随机 UUID `execution_id` 同时作为执行标识和租约所有权令牌，租约 20 秒；探测上下文 12 秒（prober 自身约 10 秒），保存 2 秒。领取即推进计划，失败保存不重探旧轮次；过期租约先废弃旧标识并推进未来计划。
- 配置版本更新时保留未过期租约，使旧 worker 拒写且不会立即与新任务重叠；最迟租约到期后恢复。连接指纹由数据库 SHA-256 计算，历史仅存指纹、不存凭证；HTTP 不返回指纹或原始错误。
- 保存锁住配置与当前代理，校验令牌、版本、有效租约、连接指纹及可监测状态。成功样本才写延迟，数据库错误仅记监测日志，不写线路失败。
- 原始数据保留 7 天；每分钟单批最多删除 5000 条过期／已删除代理样本及 1000 份孤立配置。暂停后继续清理。回退应用可保留新增表，不自动回滚 migration 或删数据。
- 过期阈值为 `3 × interval + 16` 秒；趋势空桶为空，失败延迟为空。浏览器每 15 秒刷新，仅打开时执行；关闭／切换取消旧请求并以请求序号拒绝旧响应。
