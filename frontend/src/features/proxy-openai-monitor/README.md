# 代理 OpenAI 监测与总览

入口：代理管理页右上角「代理延迟总览」，页面路径 `/admin/proxies/monitor`，管理员权限。各行「详情 / 配置」复用原有监测弹窗；不会读取代理凭证来打开详情。

## 稳定趋势曲线（首屏）

- 总览首屏直接显示多线路延迟与连通成功率曲线，默认选取当前页已开启且可监测的线路；最多10条，可展开选择，点击图例隐藏单条曲线。
- 延迟默认看成功样本P95，可切换成功均值。用尖峰和波动观察抖动，用成功率下跌观察失败；悬停显示该桶样本数和失败数。没有成功样本时不填0延迟，没有采样的桶保持断线。
- 1小时按1分钟、24小时按5分钟、7天按1小时聚合。桶级P95独立计算；不平均桶P95充当总体P95。
- 当前页线路重新排序不会重置已选线路；切换分页会重新选取，取消全部选择后不发送曲线请求。页面隐藏／退出、切换选择或范围会取消旧请求并拒绝旧响应。
- API：`GET /api/v1/admin/proxies/openai-monitor/trends?ids=1,2&hours=24&until=<overview.to>`；最多10个唯一正整数ID，沿用管理员权限、当前连接指纹隔离及10秒查询上限。一个批量查询返回所有选中线路和空桶；沿用总览截止时间。返回 `from`、`to`、`bucket_seconds`、`series[{id,name,points}]`。
- 曲线与总览独立报错／重试，保留各自上次成功结果及真实时间；首屏改为正常纵向布局，曲线在上、明细表在下，避免固定表格布局挤压曲线。

## 总览闭环

- 默认近24小时，支持1小时／24小时／7天；展示全部未删除代理，包括停用、过期和未开启监测的代理。
- 展示监测状态、最新延迟、成功率、成功平均延迟、P95、样本／失败数和最近采样时间。
- 名称搜索（最多100个字符，`%`、`_` 按普通字符匹配）、监测开启／关闭筛选，最新延迟／失败数／P95／成功率／名称排序；每页50条。
- 页面可见时每15秒刷新；隐藏或退出时取消请求，快速切换时拒绝旧响应。刷新失败保留上次成功数据并提示；筛选切换会清空旧结果。
- 状态区分停用／过期、暂停、当前连接暂无样本、样本过期、连通成功与失败。暂停仍保留历史；延迟与P95仅用成功样本，失败不记为0ms。
- 总览为实时排序，跨页之间数据会更新，不承诺固定排序快照；单代理明细继续使用原来的固定时间区间分页。

## 最小接入

- 后端实现：`backend/internal/features/proxyopen/overview.go`；在原feature管理员路由组内增加GET `/api/v1/admin/proxies/openai-monitor/overview`。
- 参数：`hours=1|24|168`、`page=1..2000`、`search`、`mode=all|enabled|paused`、`sort=latency|failures|p95|success_rate|name`。
- 返回：`rows`、`total`、`page`、`page_size`、`from`、`to`。行仅包含代理ID／名称／状态、监测配置、当前连接最新样本及汇总，不返回地址、凭证或指纹。
- 以只读repeatable-read事务统一时间和配置快照，复用现有连接指纹、资格判定及原始样本统计口径；复用历史索引，整体查询10秒超时。仅执行一个分页API请求，不从浏览器逐个拉完整报表；数据库仍需扫描匹配代理在区间内的成功／失败样本来完成全局排序。
- 前端实现留在本feature；公共改动仅管理员路由记录、代理页入口及中英文标题／说明。没有新migration、依赖、调度、用量、计费或代理健康行为变更。
